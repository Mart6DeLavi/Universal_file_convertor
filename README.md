# Universal File Converter

Локальное настольное приложение для преобразования таблиц, текстовых и офисных документов. Работает без загрузки файлов в интернет, показывает только реально поддерживаемые направления и не перезаписывает существующие файлы без подтверждения.

Приложение написано на Python с графическим интерфейсом на CustomTkinter. Офисные преобразования выполняются через LibreOffice в headless-режиме.

## Назначение

Пользователь выбирает исходный файл и папку назначения, видит доступные для этого файла форматы, запускает конвертацию и получает готовый результат. Полный сценарий выполняется в GUI, без терминала. Если LibreOffice не установлен, зависящие от него направления не отображаются и не считаются доступными.

## Основные возможности

- Выбор исходного файла и папки назначения через системные диалоги.
- Отображение имени, пути, расширения и размера исходного файла.
- Динамический список целевых форматов, зависящий от исходного файла и установленных зависимостей.
- Фоновая конвертация: интерфейс не зависает во время работы.
- Индикатор выполнения и понятный итоговый статус.
- Защита от случайной перезаписи: подтверждение, автоматическое уникальное имя или отмена.
- Проверка входных данных, каталога назначения, зависимостей и результата конвертации.
- Сохранение польских, кириллических и других Unicode-символов.
- Открытие готового файла и его папки из интерфейса.
- Логирование операций и ошибок.
- Тёмная и светлая темы оформления.

## Поддерживаемые форматы

Исходные форматы: CSV, JSON, TXT, DOCX, ODT.

Целевые форматы: CSV, JSON, TXT, DOCX, ODT, PDF.

PDF поддерживается только как целевой формат. Извлечение содержимого из PDF не реализовано.

## Матрица конвертаций

| № | Исходный | Целевой | Движок | Что сохраняется | Ограничения |
|---:|---|---|---|---|---|
| 1 | CSV | JSON | `csv`, `json` | Заголовки, порядок колонок и ключей, Unicode, пустые строки | Одна таблица; типы не выводятся автоматически |
| 2 | JSON | CSV | `csv`, `json` | Массив объектов, объединённый набор ключей, Unicode | Верхний уровень — массив объектов; вложенность сериализуется в ячейку |
| 3 | TXT | DOCX | `python-docx` | Каждая строка как отдельный абзац, Unicode | Переносы строк считаются границами абзацев; оформление не создаётся |
| 4 | DOCX | TXT | `python-docx` | Текст абзацев и таблиц в порядке документа | Стили, изображения, колонтитулы и разметка не переносятся |
| 5 | TXT | PDF | `reportlab` | Текст, Unicode, перенос длинных строк, разбиение на страницы | Базовые поля A4; изображения, ссылки и rich-text не поддерживаются |
| 6 | DOCX | PDF | LibreOffice | Вёрстка и оформление документа в пределах возможностей LibreOffice | Требуется установленный LibreOffice |
| 7 | ODT | PDF | LibreOffice | Вёрстка и оформление документа в пределах возможностей LibreOffice | Требуется установленный LibreOffice |
| 8 | DOCX | ODT | LibreOffice | Структура и оформление документа | Требуется установленный LibreOffice |
| 9 | ODT | DOCX | LibreOffice | Структура и оформление документа | Требуется установленный LibreOffice |
| 10 | ODT | TXT | `odfpy` | Текст абзацев, заголовков, списков и таблиц | Оформление и нетекстовые объекты не переносятся |

Все 10 направлений зарегистрированы в реестре. Направления 6–9 становятся видимыми только при доступном LibreOffice.

## Семантика CSV → JSON

- Кодировка — UTF-8; BOM поддерживается через `utf-8-sig`.
- Первая непустая строка считается строкой заголовков.
- Разделитель определяется автоматически среди `,`, `;`, табуляции и `|`. Можно задать разделитель явно через переменную окружения `UFC_CSV_DELIMITER` (один символ, для табуляции — `\t`).
- Каждая строка данных становится JSON-объектом. Порядок ключей соответствует порядку колонок.
- Все значения остаются строками. Числа, даты, `true`/`false` и `null` автоматически не распознаются.
- Пустое значение остаётся пустой строкой.
- Поддерживаются кавычки, запятые внутри значений и многострочные поля.
- Пустые и дублирующиеся заголовки отклоняются: преобразование было бы неоднозначным.
- Количество полей в каждой строке должно совпадать с количеством заголовков.
- Пустой файл, файл без заголовков и файл без строк данных считаются ошибкой.
- Результат записывается как JSON-массив с отступом 2 и без ASCII-экранирования Unicode.

Пример:

```csv
imię,nazwisko,uwagi
Jan,Kowalski,"Zażółć gęślą jaźń"
Anna,Nowak,
```

```json
[
  {
    "imię": "Jan",
    "nazwisko": "Kowalski",
    "uwagi": "Zażółć gęślą jaźń"
  },
  {
    "imię": "Anna",
    "nazwisko": "Nowak",
    "uwagi": ""
  }
]
```

## Семантика JSON → CSV

- Верхний уровень — массив JSON-объектов. Пустой массив допустим и создаёт пустой CSV-файл.
- Каждый элемент массива должен быть объектом. Массив примитивов или смешанный массив отклоняется.
- Заголовки формируются из ключей в порядке их первого появления.
- Если ключ отсутствует в объекте, ячейка остаётся пустой.
- Вложенные объекты и массивы записываются в ячейку как компактная JSON-строка.
- `true` и `false` записываются как `true` и `false`, `null` — как пустая ячейка.
- Невалидный JSON приводит к контролируемой ошибке с номером строки и колонки.
- CSV записывается в UTF-8 с `newline=""`, поэтому кавычки и переносы строк экранируются корректно.

Пример:

```json
[
  {"imię": "Jan", "aktywny": true, "adres": {"miasto": "Łódź"}},
  {"imię": "Anna", "aktywny": false}
]
```

```csv
imię,aktywny,adres
Jan,true,"{""miasto"":""Łódź""}"
Anna,false,
```

Поток выполнения: GUI → валидаторы → реестр → сервис → конкретный конвертер. Сервис создаёт временный каталог внутри папки назначения, проверяет результат и только затем атомарно заменяет целевой файл через `os.replace`. Исходный файл не изменяется.

## Требования

- Python 3.11 или новее. Проект проверен на Python 3.14.8.
- Tk 8.6 или новее. Для CustomTkinter нужен Python, собранный с поддержкой Tk.
- macOS, Windows или Linux.
- LibreOffice — только для направлений DOCX → PDF, ODT → PDF, DOCX → ODT и ODT → DOCX.

macOS/Linux:

## Установка LibreOffice

LibreOffice нужен для четырёх офисных направлений. Без него приложение продолжает работать, но эти направления скрываются.

macOS:

```bash
brew install --cask libreoffice
```

Альтернатива — скачать установщик с [libreoffice.org](https://www.libreoffice.org/download/) и перетащить LibreOffice в `/Applications`.

Windows:

Скачайте и установите LibreOffice с [libreoffice.org](https://www.libreoffice.org/download/). Обычно исполняемый файл находится по пути:

```text
C:\Program Files\LibreOffice\program\soffice.exe
```

Debian/Ubuntu:

```bash
sudo apt update
sudo apt install libreoffice
```

Fedora:

```bash
sudo dnf install libreoffice
```

Arch Linux:

```bash
sudo pacman -S libreoffice-fresh
```

Проверка установки:

```bash
soffice --version
```

На macOS можно проверить напрямую:

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --version
```

### Настройка пути к LibreOffice

Приложение ищет `soffice` в таком порядке:

1. Переменная окружения `UFC_SOFFICE`.
2. Переменная окружения `LIBREOFFICE_PATH`.
3. Ключ `soffice_path` в файле `~/.config/universal-file-converter/config.json`.
4. Команды `soffice` и `libreoffice` в `PATH`.
5. Стандартные каталоги установки macOS, Windows и Linux.

Пример для macOS/Linux:

```bash
export UFC_SOFFICE="/Applications/LibreOffice.app/Contents/MacOS/soffice"
```

Пример для Windows PowerShell:

```powershell
$env:UFC_SOFFICE = "C:\Program Files\LibreOffice\program\soffice.exe"
```

Пример `config.json`:

```json
{
  "soffice_path": "/Applications/LibreOffice.app/Contents/MacOS/soffice"
}
```

Путь к файлу конфигурации: `~/.config/universal-file-converter/config.json`. На Windows используется домашний каталог текущего пользователя.

## Обработка ошибок и безопасность

- Проверяется существование исходного файла, его тип и поддерживаемое расширение.
- Проверяется, что целевой формат зарегистрирован, а необходимая зависимость доступна.
- Проверяется существование каталога назначения и возможность записи в него.
- Существующий файл не перезаписывается без явного подтверждения. В диалоге можно выбрать перезапись, уникальное имя вида `имя (1).ext` или отмену.
- Недопустимые имена файлов, несовпадение расширения и совпадение исходного и целевого пути отклоняются до запуска.
- Конвертация выполняется во временном каталоге внутри папки назначения. Итоговый файл появляется только после успешной проверки.
- Проверяется, что конвертер создал файл и что он не пуст (кроме пустого JSON-массива, преобразуемого в пустой CSV).
- Для LibreOffice проверяются код возврата, тайм-аут 120 секунд, наличие и размер результата, а также сохраняются `stdout` и `stderr`.
- LibreOffice запускается с изолированным временным профилем, чтобы не конфликтовать с уже открытым экземпляром.
- Внешние процессы запускаются списком аргументов с `shell=False`.
- Ошибки показываются в GUI с пояснением и записываются в журнал. Приложение не сообщает об успехе, если файл не создан.
- Исходный файл открывается только для чтения и не изменяется.

## Логирование

Журнал: `logs/converter.log`.

Используется `RotatingFileHandler`: размер файла до 1 МБ, хранится до трёх резервных копий. Записываются начало конвертации, источник, целевой формат, результат, длительность и исключения.

Если каталог журналов недоступен, приложение продолжает работу и не завершается из-за ошибки логирования.

## Известные ограничения

- Обрабатывается один файл за операцию; пакетная конвертация не реализована.
- Поддерживаются только перечисленные направления. PDF не является исходным форматом.
- Старый формат `.doc` не поддерживается; используются `.docx` и `.odt`.
- CSV и JSON читаются только в UTF-8 (BOM допускается). Другие кодировки нужно предварительно преобразовать.
- В CSV используется один разделитель. Настройка доступна через `UFC_CSV_DELIMITER`, но не через GUI.
- JSON → CSV не разворачивает вложенные структуры в отдельные колонки, а сериализует их в ячейку.
- TXT → DOCX не создаёт стили, списки и таблицы: каждая строка становится абзацем.
- DOCX → TXT и ODT → TXT извлекают только текст; оформление, изображения, колонтитулы и сноски не сохраняются.
- TXT → PDF создаёт простой документ A4 без rich-text. Для Unicode используется первый найденный системный шрифт Arial/DejaVu/Liberation.
- Качество DOCX/ODT → PDF и DOCX ↔ ODT зависит от установленной версии LibreOffice. Сложные шрифты, макросы и внешние объекты могут отображаться иначе.
- Офисные конвертации ограничены тайм-аутом 120 секунд.
- Пароли, цифровые подписи и PDF/A не поддерживаются.
- Приложение не загружает файлы в сеть и не использует облачные сервисы.
